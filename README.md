## Kaiwi Coast website

volunteer hub for the Kaiwi Coast, built for Livable Maunalua Hui.

## Run it on your computer

navigate to folder in command line

npm install
npm run dev      # opens a live preview at http://localhost:4321
npm run build    # creates the finished site in the dist/ folder
npm run preview  # preview the finished build

## Updating events (no code)

events live in Google Calendar. Add, edit, or delete them there and the website updates automatically.
